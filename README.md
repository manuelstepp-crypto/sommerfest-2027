# Sommerfest am Sonnenhang 2027 – Save the Date

Landingpage mit Anmeldeformular für das Sommerfest am Sonnenhang, 23.–25. Juli 2027, Waldenbuch.

- Statische Seite (HTML/CSS/JS), gehostet über GitHub Pages
- Anmeldungen landen in Supabase (Projekt „Sommerfest 2027", Tabelle `save_the_date`)
- Der Publishable Key im Frontend ist öffentlich; Row Level Security erlaubt nur das Eintragen, kein Lesen
- Planung: OneDrive `3_Engagement für Freunde/Sommerfest 2027/`
